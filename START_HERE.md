# Start here

1. **Install** (Node 24+, pnpm 12):

```bash
corepack enable
pnpm install
pnpm dev
```

2. Open [http://localhost:3000](http://localhost:3000).

3. Teach something. There is **no API key** and **no OpenAI** — replies are mocked from what you type.

Live demo: [https://stupid.dev.furet.network](https://stupid.dev.furet.network)

More detail: `README.md`, `SETUP.md`, `HACKATHON_READY.md`.
